Log viewer

A live stream: it follows the tail until you scroll up, then counts new lines in a pill. Search with Enter / Shift Enter, filter by level, wrap, jump to the next error, copy a line. React: <LogViewer lines />. Classes: .oq-log, __line[data-level], __pill, --wrap.

JSON inspector

Collapsible, type-coloured, with sizes. The filter keeps matching branches open. Hover a row to copy its value or path. Keyboard: arrows, c copies the value, p the path. React: <JsonInspector value defaultExpandDepth={1} />. Classes: .oq-json, __row, __key, __value.is-string|number|boolean|null.

Diff view

Line diff (shortest edit script) with changed words marked inside each line; long unchanged runs fold behind a button. React: <DiffView oldText newText />; the diff itself is diffLines(a, b). Classes: .oq-diff, --split, __line.is-add|is-del, __skip, ins/del.oq-diff__word.
