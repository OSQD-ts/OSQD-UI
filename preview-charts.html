Series palette

Eight categorical slots, --oq-series-1 … --oq-series-8, assigned in order and never cycled. They are separate from the intents: success, warning and danger mean state and stay reserved for it. Dark themes get one set of steps and light themes another; both are checked for colour-blind separation against every theme's surface. Every chart also has a legend, a tooltip and a table, so colour is never the only cue.

import { BarChart } from "@osqd/ui";

<BarChart
  label="Requests per region"
  data={rows}            // [{ region: "eu-central", allowed: 4210, blocked: 312 }, …]
  x="region"
  series={[{ key: "allowed", label: "Allowed" }, { key: "blocked", label: "Blocked" }]}
  stacked
  table="toggle"
/>

Ramps & fill classes

A sequential ramp --oq-seq-0…12 for magnitude and an ordinal ramp --oq-ord-1…5 for stages, both mixed from the theme's surface and primary, so they follow every theme. One class colours any mark: .oq-fill-series-N, .oq-fill-seq-N, .oq-fill-ord-N set the SVG fill, the bar background and the intent pair; .oq-stroke-series-N sets a line. .oq-w-0…100 (steps of 5) set --value for static markup; from script, set --value directly. Nothing on this page uses a style attribute.

Plain HTML

Vanilla SVG chart recipe

Without React, draw the geometry yourself and let the kit's classes do the styling: svg.oq-chart__svg, g.oq-chart__grid lines, text.oq-chart__tick, path.oq-chart__line.oq-stroke-series-N, path.oq-chart__area.oq-fill-series-N, rect.oq-chart__bar.oq-fill-series-N, and a legend of .oq-chart__legend-item buttons with .oq-chart__swatch.oq-fill-series-N. Every chart also needs a table view (details.oq-chart__table) and an accessible name. Draw at the size you measure (a ResizeObserver on .oq-chart__plot) so 11 px ticks stay 11 px; this static example keeps its natural 480 × 180 and only shrinks to fit.
