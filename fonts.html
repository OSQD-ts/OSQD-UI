Typefaces

OSQD fonts

Three families drawn for the kit, each a sans and a monospaced companion in eight weights from ExtraLight to Black, every one with an italic; Sans and Tech also come Condensed for dense tables, and every sans has a Caption cut for small text and a Display cut for large headings. Proportional and slashed figures, fractions, superscripts and Clear's distinguishing forms are OpenType features. Utilitarian first: tall x-height, tabular figures, open counters and clear joins at 12–14 px, so tables, logs and dense forms stay readable. Licensed under the SIL Open Font License 1.1.

<html class="oq" data-font="clear">   <!-- tech | clear | sans | system -->

font-family: var(--oq-font-sans);   /* OSQD Sans, OSQD Tech or OSQD Clear */
font-family: var(--oq-font-mono);   /* the matching mono */
font-family: var(--oq-font-caption);  /* small text; the kit's chips, badges and overlines use it */
font-family: var(--oq-font-display);  /* large headings; the kit's .oq-h1 and .oq-h2 use it */
font-family: var(--oq-font-condensed);  /* Sans or Tech Condensed; .oq-condensed sets it on a subtree */
font-weight: 200 … 900;  font-style: italic;
<div data-font="condensed">   <!-- or tech-condensed: the whole subtree in the condensed cut -->

OpenType features

Figures, fractions and alternates

Figures are tabular by default, so columns line up. Each feature below is a class in the kit and a standard CSS property, so it works with any font stack.
