Split panes

Drag the line, or focus it and use the arrow keys (Shift for bigger steps, Home/End for the limits). Double-click or Enter collapses the first pane. The outer split remembers its size. .oq-split · <SplitPane>

src/policy.tsTypeScript
export function decide(findings: Finding[], policy: Policy): Decision {
  const score = findings.reduce((s, f) => s + f.score, 0);
  if (score >= policy.block) return { action: "block", score };
  if (score >= policy.challenge) return { action: "challenge", score };
  return { action: "allow", score };
}

Shortcuts overlay

Press ? anywhere outside a text field. In React, <ShortcutsProvider> holds a registry; each useShortcut({ keys, label, group, handler }) adds one, and the overlay lists whatever is registered right now, grouped.
