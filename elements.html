Custom elements

One script makes plain HTML interactive. Every element works in the light DOM and enhances markup that already uses the kit's classes, so a page looks right before the script loads. This page runs on that script alone — it has no other JavaScript.

html 
<link rel="stylesheet" href="node_modules/@osqd/ui/dist/osqd-ui.css"><script src="node_modules/@osqd/ui/assets/osqd-ui-elements.js" defer></script><!-- or, with a bundler: import "@osqd/ui/elements/auto"; -->

Theme select

<oq-theme-select>

<oq-theme-select> binds a select to data-theme and remembers the choice. Without a <select> inside, it builds one with every built-in theme. The one in the top bar is this element.

Eventsoq-change {theme}
html 
<oq-theme-select target="#theme-demo" storage-key="" default="paper"></oq-theme-select><div class="oq-paper oq-p-4" id="theme-demo" style="background: var(--oq-bg)">  <button class="oq-btn oq-sm">Themed only in here</button></div>

Dialog

<oq-dialog>

<oq-dialog> around a native <dialog>. Any [data-oq-open="id"] opens it; Escape, the backdrop and [data-close] close it. The open attribute works both ways.

Eventsoq-open oq-close {returnValue}

Toasts

<oq-toast-region> is the stack (max, duration). From script: OQ.toast({ title, message, color, duration }). Without script: data-oq-toast-title / -message / -color on any clickable element.

Tag input

<oq-tag-input class="oq-tags">: Enter or comma adds, pasting a list adds them all, Backspace removes the last; duplicates and values failing pattern are refused. name keeps a hidden input for plain form posts.
